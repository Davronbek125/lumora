# Lumora

Cinematic mindfulness hero in React + Vite + Tailwind + Lucide.

## Run

```bash
cd lumora
npm install
npm run dev
```

Open the printed URL. The page renders a single fullscreen section with four crossfading background videos, a bobbing PNG overlay, the liquid-glass nav/CTA/video switcher, and dark-mode text on the "Deep Woods" video.
